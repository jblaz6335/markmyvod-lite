# Security

MarkMyVOD Lite is a local Windows desktop utility. It does not require an account, upload footage, collect telemetry, or run a background network service.

To report a suspected security issue, use the private contact form at [Blaz Algo Systems](https://blazalgosystems.netlify.app/contact/) and include the affected version, Windows version, and steps to reproduce. Do not publish sensitive details in a public issue.
